# 🛒 E-Commerce Android Application

This is a full-featured E-Commerce mobile application built using Android SDK with Firebase backend integration. It supports both **Seller** and **Buyer** functionalities, and includes essential features like user authentication, product management, real-time updates, and Google Maps integration.

## 📱 Features

### 🔐 Authentication
- Firebase Authentication for user login and registration

### 👨‍💼 Seller Features
- Add / Edit / Delete products
- View orders placed by buyers
- Order management system
- Manage stock and availability

### 🛍️ Buyer Features
- Browse product listings
- View product details
- Add to cart / place orders

### 🌍 Other Key Features
- Realtime product data with Firebase Realtime Database
- Google Maps API for address selection / location
- Lottie animations for enhanced user experience
- Admin panel for managing platform-level tasks
- Location-based delivery address via Google Maps

## 🛠️ Tech Stack

| Technology      | Description                          |

| **Android SDK** | Native Android development           |
